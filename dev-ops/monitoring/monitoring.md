## sFlow

Refers to sampled flow, an industry-standard protocol for monitoring high-speed networks. Instead of inspecting every single packet (which is costly), sFlow samples packets and/or interface counters and sends the data to a collector for analysis. sFlow traffic is network traffic that has been sampled and exported by sFlow-enabled devices. It includes metadata such as source/destination IP, protocol, VLAN, etc., which can be used for traffic analysis, network billing, capacity planning.
