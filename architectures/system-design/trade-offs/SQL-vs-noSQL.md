# SQL vs NoSQL

### SQL

- Relational databases store data in rows and columns
- Each record conforms to a fixed schema (structured schema)
- Powerful for complex queries and joining data from multiple tables (data relations)
- Vertically scalable
- ACID compliant with transactions (data integrity)

### NoSQL

- NoSQL databases have different data storage models: key-value, document, graph, and columnar
- Suitable for schemas that are dynamic and evolving (more flexibility)
- Sacrifices ACID compliance for performance and scalability through horizontal scaling (sharding)
